# Simple Line Editor - Help

## About

This is a command-line line editor written in C.
It allows the user to insert, delete, and display lines of a document.

---

## Commands

### i - Insert Line

Inserts a new line at the given line number.

#### Usage

```text
Enter command: i
Enter line number: 2
Enter text: Hello World



d - Delete Line
Deletes a line at the given line number.

Usage:
Enter command: d
Enter line number: 2

p - Display Document
Displays all lines with line numbers.

Usage:
Enter command: p

q - Quit
Exits the editor.

Usage:
Enter command: q
